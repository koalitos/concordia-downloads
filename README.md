# Concórdia — instaladores

Aqui ficam só os instaladores do app de desktop do
[Concórdia](https://concordia.app.br). O código-fonte é privado; este
repositório existe porque anexo de release de repositório privado não pode
ser baixado sem login, e a página de download precisa de link aberto.

**[Baixar a versão mais recente](https://github.com/koalitos/concordia-downloads/releases/latest)**

| Sistema | Arquivo |
|---|---|
| macOS, M1 em diante | `Concordia-<versão>-arm64.dmg` |
| macOS Intel | `Concordia-<versão>-x64.dmg` |
| Windows 64 bits | `Concordia-Setup-<versão>.exe` |

Os instaladores não são assinados. No macOS, abra com o botão direito →
Abrir. No Windows, clique em "Mais informações" → "Executar assim mesmo".
